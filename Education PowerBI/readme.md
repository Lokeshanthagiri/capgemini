# Education Analytics Dashboard using Power BI

## Overview

The **Education Analytics Dashboard** is an interactive Power BI report designed to analyze student performance, attendance, enrollment, and demographic trends. It provides educators, administrators, and stakeholders with actionable insights to support data-driven decision-making.

## Features

### Executive Overview Dashboard

The report contains a comprehensive executive dashboard with:

* **Total Students**
* **Average Exam Score**
* **Average Attendance**
* **Pass Percentage**
* **Average Assignment Score**

### Visualizations

1. **Students by Course**

   * Clustered Bar Chart
   * Displays student enrollment across different courses.

2. **Average Exam Score by Course**

   * Clustered Column Chart
   * Compares academic performance across courses.

3. **Attendance Percentage by Course**

   * Line Chart
   * Tracks attendance trends by course.

4. **Gender Distribution**

   * Donut Chart
   * Shows the proportion of students by gender.

5. **Students by City**

   * Map Visualization
   * Geographic distribution of students.

6. **Interactive Filters (Slicers)**

   * Academic Year
   * Course
   * Teacher
   * City
   * Grade
   * Gender

## Dataset

The dashboard uses a dataset named **Student_Data** containing information such as:

* Student ID
* Course
* Academic Year
* Teacher
* City
* Gender
* Grade
* Attendance Percentage
* Exam Scores
* Assignment Scores

## Key Metrics

| Metric                   | Description                            |
| ------------------------ | -------------------------------------- |
| Total Students           | Total number of enrolled students      |
| Average Exam Score       | Average score achieved in examinations |
| Average Attendance       | Average attendance percentage          |
| Pass Percentage          | Percentage of students who passed      |
| Average Assignment Score | Average assignment performance         |

## Tools & Technologies

## Dashboard Objectives

* Monitor student performance.
* Analyze attendance trends.
* Identify high-performing courses.
* Understand demographic distribution.
